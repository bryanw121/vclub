# vteam ideas (daily ideation log)

This branch is written by the daily "vteam ideation" scheduled task. It never touches `main`.

- `ideas/YYYY-MM-DD.md`: that day's proposals (problem, design, mocks, sequence diagram for backend changes).
- `ideas/assets/YYYY-MM-DD/*.png`: mock images.
- `ideas/log.json`: every idea ever proposed, with status `proposed`, `approved` (with its issue number) or `rejected`, so runs don't repeat themselves.

To approve: open that day's run in Claude and reply, e.g. "approve 1 and 3", "reject 2 because ...". Approved ideas become fully designed vteam issues.
